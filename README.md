# 💌 Undangan Pernikahan Asha & Yusnar

Website undangan pernikahan bertema white & soft pink, dengan ucapan, konfirmasi kehadiran, dan dashboard admin yang tersimpan di Firebase Firestore.

Dikembangkan dari template [dewanakl/undangan](https://github.com/dewanakl/undangan) (lisensi MIT).

## 📦 Panduan

- **[Menghubungkan Firebase](docs/TUTORIAL_FIREBASE.md):** membuat project, rules, dan akun admin.
- **[Mengganti foto, musik, dan teks](docs/TUTORIAL_ASET.md):** daftar aset dan cara menggantinya.

## 🚀 Menjalankan

```bash
npm install
npm run dev            # http://localhost:8080
npm run build:public   # hasil siap unggah di folder public
```

Halaman tamu ada di `/`, dashboard admin di `/dashboard.html`.

## ⚙️ Tech stack

- Bootstrap 5.3.8
- AOS 2.3.4
- Fontawesome 7.1.0
- Canvas Confetti 1.9.3
- Firebase Firestore Lite & Authentication
- Google Fonts
- Vanilla JS
